## 💡 ИДЕИ ИЗ ОБСУЖДЕНИЙ (не оформлены в задачи)

### Финансовая аналитика
- **Breakeven по мастеру:** при каком количестве клиентов смена окупается
- **ROI косметики:** сколько приносит каждый рубль вложенный в расходники
- **Сезонность:** сравнение аналогичных периодов прошлого года
- **Прогноз выручки:** на основе записей которые уже есть в расписании

### Операционная аналитика
- **Загрузка по типу услуг:** SPA vs массаж — разные циклы возврата
- **Парные программы:** отдельный учёт (два мастера = особая экономика)
- **Среднее время от записи до визита:** насколько далеко вперёд записываются
- **Конверсия онлайн-запись → визит:** % отмен после онлайн записи

### Управление командой
- **Рейтинг мастеров** по CM/LH за период
- **Табель учёта рабочего времени** — автоматически из shifts
- **История бонусов** по мастеру за все периоды

### Клиентская база
- **LTV клиента** — сколько принёс за всё время
- **Сегментация:** VIP (сертификаты >15К) / Regular / Fitmost / Разовые
- **Когортный анализ:** выживаемость клиентов по месяцу первого визита
- **Клиенты без email/телефона** — риск потери базы

## 🏗 АРХИТЕКТУРА ДАННЫХ — логика учёта

### Источники выручки
```
YCLIENTS transactions (type_title):
  - "Оказание услуг"    → revenue_services
  - "Продажа сертификатов" → revenue_certificates  
  - "Продажа абонементов"  → revenue_abonements
Bank transactions (Fitmost, по period) → revenue_fitmost
```

### Источники расходов
```
bank_transactions (project=salon):
  - salon_rent    → аренда (по period)
  - cosmetics     → косметика
  - bank_fee      → банковские комиссии
  - overdraft_interest → проценты по овердрафту
  - taxes         → налоги
  - marketing     → реклама

personal_transactions (project=salon):
  - salary        → зарплата мастеров
  - materials     → расходники (WB, аптека)
  - marketing     → реклама (VK, Telegram, PushSMS)
  - it            → YCLIENTS, программы
  - training      → обучение
```

### Логика мастеров
```
Зарплата: 5 000 ₽ фикс за смену
Бонус: % от продаж (рассчитывается вручную раз в месяц)
Аванс: наличные от клиентов которые мастер забирает в конце смены
Двойная смена (выходные): 2 мастера, выручка ÷ 2
Выход под запись: оплата = стоимость конкретной услуги
Абонемент: цена сеанса = прайс × 0.7 (скидка 30%)
Fitmost запись: цена = прайс × 0.65 (скидка 35%)
```

## 💡 ИДЕИ ИЗ ОБСУЖДЕНИЙ (не оформлены в задачи)

### Финансовая аналитика
- **Breakeven по мастеру:** при каком количестве клиентов смена окупается
- **ROI косметики:** сколько приносит каждый рубль вложенный в расходники
- **Сезонность:** сравнение аналогичных периодов прошлого года
- **Прогноз выручки:** на основе записей которые уже есть в расписании

### Операционная аналитика
- **Загрузка по типу услуг:** SPA vs массаж — разные циклы возврата
- **Парные программы:** отдельный учёт (два мастера = особая экономика)
- **Среднее время от записи до визита:** насколько далеко вперёд записываются
- **Конверсия онлайн-запись → визит:** % отмен после онлайн записи

### Управление командой
- **Рейтинг мастеров** по CM/LH за период
- **Табель учёта рабочего времени** — автоматически из shifts
- **История бонусов** по мастеру за все периоды

### Клиентская база
- **LTV клиента** — сколько принёс за всё время
- **Сегментация:** VIP (сертификаты >15К) / Regular / Fitmost / Разовые
- **Когортный анализ:** выживаемость клиентов по месяцу первого визита
- **Клиенты без email/телефона** — риск потери базы

## 🏗 АРХИТЕКТУРА ДАННЫХ — логика учёта

### Источники выручки
```
YCLIENTS transactions (type_title):
  - "Оказание услуг"    → revenue_services
  - "Продажа сертификатов" → revenue_certificates  
  - "Продажа абонементов"  → revenue_abonements
Bank transactions (Fitmost, по period) → revenue_fitmost
```

### Источники расходов
```
bank_transactions (project=salon):
  - salon_rent    → аренда (по period)
  - cosmetics     → косметика
  - bank_fee      → банковские комиссии
  - overdraft_interest → проценты по овердрафту
  - taxes         → налоги
  - marketing     → реклама

personal_transactions (project=salon):
  - salary        → зарплата мастеров
  - materials     → расходники (WB, аптека)
  - marketing     → реклама (VK, Telegram, PushSMS)
  - it            → YCLIENTS, программы
  - training      → обучение
```

### Логика мастеров
```
Зарплата: 5 000 ₽ фикс за смену
Бонус: % от продаж (рассчитывается вручную раз в месяц)
Аванс: наличные от клиентов которые мастер забирает в конце смены
Двойная смена (выходные): 2 мастера, выручка ÷ 2
Выход под запись: оплата = стоимость конкретной услуги
Абонемент: цена сеанса = прайс × 0.7 (скидка 30%)
Fitmost запись: цена = прайс × 0.65 (скидка 35%)
```
