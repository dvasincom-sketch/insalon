## Что изменилось

Frontend был рефакторизован. Раньше весь JS жил в одном файле
`static/v2/index.html` (2472 строки). Теперь структура такая:

static/v2/
├── index.html        ← только HTML, без инлайн JS
└── js/
    ├── config.js     ← константы: API, TODAY, YEAR, MONTH, MONTHS_RU, STAFF_COLORS
    ├── utils.js      ← formatMoney(n), formatK(n)
    ├── api.js        ← fetchData(url) — единственное место с fetch
    ├── router.js     ← showScreen(name), lazy-load флаги
    ├── pulse.js      ← экран Пульс: loadKPI, loadPulse, loadNorthStar, loadHeatmap
    ├── pl.js         ← экран P&L: loadPL
    ├── staff.js      ← экран Сотрудники: loadStaff
    ├── schedule.js   ← расписание + showStaffTab
    ├── payroll.js    ← ведомость: loadPayroll, applyPayrollFilter
    ├── checks.js     ← проверки: loadChecks
    ├── obligations.js← обязательства: loadObligations
    ├── modal.js      ← drill-down: showDetail
    ├── fot.js        ← ФОТ: loadFotData, fotData, fotPeriod + все функции расчёта
    └── main.js       ← init() — точка входа

## Важные правила архитектуры

1. Без ES modules — обычные <script> теги, все функции глобальны
2. Порядок подключения критичен: config → utils → api → router → [экраны] → fot → main
3. Изменяемый стейт только в fot.js (fotData, fotPeriod)
4. window.* флаги запрещены — используем let в router.js
5. Все fetch только через fetchData() из api.js
